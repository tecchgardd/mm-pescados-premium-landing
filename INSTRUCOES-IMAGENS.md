# 📸 Instruções para Adicionar Imagens

## Imagens Necessárias para o Projeto

Coloque as seguintes imagens na pasta `assets/img/`:

### 1. **Seção de Produtos (Vitrine)**
- `peixe-inteiro.jpg` - Foto de peixe fresco inteiro
- `file-premium.jpg` - Foto de filés premium/cortados
- `frutos-do-mar.jpg` - Foto de frutos do mar (camarão, lula, etc)
- `congelados-empanados.jpg` - Foto de produtos congelados e empanados

### 2. **Seção SISBI**
- ✅ `sisbi.jpg` - JÁ EXISTE no projeto

### Recomendações

- **Tamanho**: Otimize as imagens para web (máximo 500KB cada)
- **Formato**: JPG ou PNG
- **Proporção**: Mantenha aproximadamente a mesma proporção para uma galeria uniforme
- **Qualidade**: Use imagens de boa qualidade para manter o padrão premium

## Estrutura de Pastas

```
mm-pescados-premium-landing/
├── assets/
│   ├── img/
│   │   ├── sisbi.jpg ✅
│   │   ├── peixe-inteiro.jpg (ADICIONAR)
│   │   ├── file-premium.jpg (ADICIONAR)
│   │   ├── frutos-do-mar.jpg (ADICIONAR)
│   │   ├── congelados-empanados.jpg (ADICIONAR)
│   │   └── ... (outras imagens)
│   └── videos/
└── ...
```

## Como Fazer Upload

1. Abra a pasta `assets/img/` no seu projeto
2. Adicione as 4 imagens de produtos mencionadas acima
3. O site irá carregar automaticamente as imagens

Qualquer dúvida, é só chamar! 🐟
