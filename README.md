# MM Pescados Premium Landing Page

Landing page em HTML, CSS e JavaScript puro.

## Estrutura limpa

- `index.html` — página principal com SEO, Open Graph e botões de WhatsApp/e-commerce.
- `styles.css` — arquivo único de estilos da landing page.
- `script.js` — arquivo único de scripts, menu mobile, animações, vídeos e links do WhatsApp.
- `assets/img/` — imagens da página.
- `assets/videos/` — vídeos do hero.
- `assets/icons/favicon.svg` — favicon.
